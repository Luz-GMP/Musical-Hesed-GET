# Como fazer um playback visual

Peças: **MM-07** (Nasceu em Belém), **MM-08** (Maravilhosa Graça, Julia Vitória), **MM-11** (Luz do Mundo), **MM-13** (Santo pra Sempre), **MM-16** (Maravilhosa Graça, Samuel Mizrahy).

O playback é uma **coreografia do telão com a música**. Se a música cresce, o visual cresce; se a música respira, o visual respira; se a música impacta, o telão responde ao impacto.

## Apresentação do storyboard musical

Use o padrão das pranchas do Dudu, conforme o [guia canônico de construção](../storyboards/guia-de-construcao.md): cabeçalho com objetivo, estilo e identificação da faixa; quadros numerados com descrição/movimento; bloco próprio de momentos musicais e impactos ligado aos IDs. Inclua também paleta com amostras e nomes, luz/atmosfera, elementos visuais, efeitos e continuidade. O loop simples que acompanha uma música também deve comunicar sua relação com ela, sem ganhar cortes ou ações desnecessárias.

Sem o master, mantenha o bloco como estudo e os tempos a definir. Uma forma de onda só deve representar áudio real identificado; o mapa textual é suficiente para registrar intenções ainda não sincronizadas. Os exemplos de tempos abaixo são ilustrativos, não medições de uma faixa do HESED.

## 1. Mapeie a faixa antes de editar

Com o **audio master definitivo** (o mesmo que vai tocar no dia), ouça a faixa inteira e anote os tempos. Use o modelo abaixo; ele pode ficar no Drive ou na própria ficha da peça.

| Tempo | Momento | O que acontece na música | Resposta visual planejada |
| --- | --- | --- | --- |
| 0:00 | Introdução | piano sozinho | imagem limpa, movimento sutil |
| 0:24 | 1º crescimento | entra bateria | luz/escala aumentam gradualmente |
| 0:48 | Refrão | | |
| 1:10 | Impacto | prato/virada | corte ou expansão no frame exato |
| ... | Clímax | | maior intensidade da peça |
| ... | Encerramento | | sustenta imagem forte ou prepara a próxima |

Dica: no editor, coloque **marcadores na timeline** em cada impacto antes de pôr qualquer imagem. Isso vira a grade do vídeo, como o grid de um layout.

## 2. Tabela de respostas

| Momento musical | Resposta visual |
| --- | --- |
| Introdução / trecho contido | Imagem mais limpa, movimento sutil, espaço visual |
| Crescimento | Aumento gradual de luz, escala, profundidade ou movimento |
| Frase de maior impacto | Entrada pontual de texto, só se fizer sentido |
| Impacto sonoro | Mudança de plano, flash controlado, expansão, corte, partículas ou transformação, **sincronizado** |
| Clímax | Imagem, luz, movimento e eventual texto chegando juntos ao ápice |
| Encerramento | Redução, sustentação de imagem forte ou transição preparada |

## 3. Texto

- **Nunca** a letra inteira. Isso aqui não é lyric video.
- Duas a quatro frases por música, no máximo, nos momentos de maior peso.
- Fonte legível de longe, alto contraste, tempo de leitura suficiente.

## 4. Não brigue com o palco

Vários playbacks acontecem com dança ou com o elenco montando o presépio (Luz do Mundo). Reserve as mudanças grandes para os momentos musicais relevantes. Telão agitado o tempo todo tira o olhar do palco.

## 5. Teste de sanidade

Assista ao alpha **sem som**. Se você consegue adivinhar onde está o refrão e o clímax só pelo vídeo, o playback está funcionando.
