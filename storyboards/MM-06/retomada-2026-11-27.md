# Retomada do nascimento em outro dispositivo · MM-06-Q04

**27/11/2026 · Isaac na Cena 3, Victor na Cena 8.** A [composição v01](q04-composicao-v01/README.md) reúne o bebê e a manjedoura com os seis planos da estrebaria MM12-Q06 V06. O quadro neutro, o parallax e a camada de fala coletiva estão disponíveis para revisão. Isaac confirma o quadro e a passagem para a MM-07 antes do reuso por Victor na Cena 8. As instruções abaixo documentam as fontes e o registro para retomar a montagem.

## Recuperar os arquivos

1. Atualize a `main` com `git pull --ff-only origin main`. Para uma máquina sem checkout, use `git clone --branch main https://github.com/Luz-GMP/Musical-Hesed-GET.git`.
2. Abra [a pasta de mídia da retomada no GitHub](midia-retomada/). Depois do pull, os arquivos ficam em `storyboards/MM-06/midia-retomada/`. O ZIP no OneDrive é uma cópia portátil opcional.
3. Na pasta de mídia, abra `interior-MM12-Q06-V06/prova-camadas.png`, depois `preview_stack.png` e `preview_shift.png` na mesma pasta. Para conferir a integridade dos PNGs, rode o comando abaixo a partir de `storyboards/MM-06/midia-retomada/`, usando o [manifesto com tamanhos e hashes](manifesto-retomada-2026-11-27.csv).

   ```powershell
   Import-Csv '../manifesto-retomada-2026-11-27.csv' | Where-Object path -like '*.png' | ForEach-Object {
     if (!(Test-Path -LiteralPath $_.path -PathType Leaf)) { throw "Arquivo ausente: $($_.path)" }
     if ((Get-FileHash -LiteralPath $_.path -Algorithm SHA256).Hash -ne $_.sha256) {
       throw "Hash divergente: $($_.path)"
     }
   }
   ```

Abra primeiro o empilhamento neutro, posicione o bebê e confira escala, apoio no piso e luz. Verifique depois as bordas dos recortes e a continuidade da mureta no deslocamento.
